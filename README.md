A one-page newspaper front page for Wednesday 25 November 2026: 36 stories,
every one dated that Wednesday, with sources named beside each story.

- Giant date masthead, six big red figures, and a "THE DAY IN UTC" timeline.
- Three illustrated leads: Asia's chip-stock crash (Kospi −6.2%), Pakistan's
  first astronaut docking at Tiangong, and the proposed US tariffs of up to
  20% on the EU and China.
- Ten more illustrated stories, a pin map (pins match story numbers 1–13),
  all 23 remaining stories listed, region bars, and a DATE CHECK that names
  the earlier-dated stories left out.

## Build

```sh
python3 render.py   # draws entry.png (1024x1024) with Pillow, locally
python3 main.py     # stdlib only: verifies entry.png, writes it to output/
```

All drawings are original, drawn in code. No network access is used.
